# Контент-ассистент PRO Женщин Москва

Помощник на базе ИИ для команды сообщества **PRO Женщин**: собирает отчёты малых групп, готовит черновики еженедельных дайджестов и помогает публиковать их во ВКонтакте — **только после проверки человеком**.

> Этот README написан для заказчиков, редакторов и партнёров.  
> Техническая документация для разработчиков: [docs/DEVELOPER.md](docs/DEVELOPER.md).

---

## Зачем это нужно

Каждую неделю лидеры малых групп сдают отчёты, а контент-команде нужно:

1. собрать информацию в одном месте;
2. написать понятный и тёплый дайджест в стиле сообщества;
3. подобрать подходящие фото из архива;
4. согласовать текст;
5. опубликовать в открытой группе ВК.

Ассистент берёт на себя рутину (сбор, черновик, подбор материалов), а **решение «публиковать или доработать» остаётся у людей**.

---

## Как это выглядит на практике

```text
Отчёт лидера (Senler)
        ↓
База отчётов в Yonote
        ↓
ИИ готовит черновик дайджеста + кандидаты фото
        ↓
Черновик в Yonote + пост в закрытой группе ВК (на утверждение)
        ↓
Редактор правит / утверждает
        ↓
Публикация в открытую группу ВК
```

**Важно:** без явного утверждения пост в открытую группу не уходит.

## Что уже умеет MVP

| Возможность | Что получает команда |
|-------------|----------------------|
| Приём отчётов | Отчёт из сценария Senler появляется в базе Yonote |
| Черновик дайджеста | Текст на русском в тоне сообщества, с опорой на отчёты |
| Фотоархив | Подбор кандидатов из утверждённых фото |
| Human-in-the-loop | Согласование в закрытой группе ВК и правка в Yonote |
| Публикация | После утверждения — пост в открытую группу |
| Панель процессов | Self-hosted n8n для сценариев и кнопок запуска |

## Из чего состоит решение (простыми словами)

- **GigaChat** — пишет черновики текстов;
- **Yonote** — база отчётов и папка черновиков;
- **ВКонтакте** — закрытая группа для согласования, открытая для публикации;
- **Senler** — сценарий, через который лидеры сдают отчёты;
- **Фотоархив** — библиотека утверждённых фото сообщества;
- **n8n** — «пульт», который связывает шаги между собой.

---

## Принципы, которые заложены в продукт

1. **Человек в контуре** — ИИ предлагает, команда решает.
2. **Без выдумок** — текст опирается на отчёты; факты не придумываются.
3. **Стиль сообщества** — тон и правила зафиксированы в промптах проекта.
4. **Безопасность** — секреты и ключи не хранятся в репозитории (только примеры `.env.example`).

## Известные рамки текущей версии (MVP)

Это не «дыры», а честные границы первой версии:

- часть сценариев в n8n может запускаться командой внедрения вручную;
- автоматическая классификация комментариев в публичном API ещё не выставлена;
- поиск фото может работать в упрощённом режиме, пока не собран полный визуальный индекс;
- вложение фото во ВК может быть упрощённым относительно полного Photos API.

Подробный план доработок — в [docs/DEVELOPER.md](docs/DEVELOPER.md).

## Для разработчиков

- установка и локальный запуск;
- Docker Compose;
- развёртывание на VPS Beget;
- переменные окружения и API.

См. **[docs/DEVELOPER.md](docs/DEVELOPER.md)** и **[docs/DEPLOY_BEGET.md](docs/DEPLOY_BEGET.md)**.

```bash
# кратко
cp .env.example .env          # заполнить секреты
python -m venv .venv
# Windows:
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
# рядом должен лежать sibling-проект tg_vk_parser с фотоархивом
docker compose up -d --build
```

Рекомендуемый Python: **3.11 или 3.12** (не 3.14).
