================================================================================

0.1. Доступы
     - [ ] Браузер открывает https://portfolio.mkluckoff.ru/health
           Ожидание: страница/JSON со status = ok
     - [ ] Есть вход в yonote (коллекции «Черновики» и БД «Отчёты малых групп»)
     - [ ] Есть доступ к закрытой группе ВК (утверждение) и открытой (публикация)
     - [ ] Есть доступ в n8n (https://n8n.mkluckoff.ru) — логин выдаёт команда внедрения
     - [ ] (Опционально) Есть тестовый сценарий Senler «отчёт малой группы»
           или договорённость с техническим специалистом о тестовой отправке отчёта

0.2. Правила безопасности теста
     - Не публиковать в открытую группу финальные материалы без явного решения заказчика
     - Для публикации использовать только тестовый/согласованный черновик
     - В открытых каналах не светить секреты, токены, пароли
